# 音樂播放器 App

一個基於 Android Jetpack Compose 開發的現代音樂播放器應用程式，提供完整的音樂播放功能和流暢的使用者體驗。

## 🎵 主要功能

### 音樂播放控制
- **播放/暫停**：直觀的播放控制按鈕
- **自動播放**：選擇歌曲後自動開始播放
- **進度追蹤**：即時顯示播放進度和剩餘時間
- **拖拽控制**：可拖動進度條跳轉到任意播放位置

### 播放模式
- **順序播放**：歌曲播放完畢後自動停止
- **隨機播放**：支援隨機播放其他歌曲
- **模式切換**：一鍵開啟/關閉隨機播放模式

## 🎨 使用者介面

### 歌曲列表
- 顯示完整的 22 首預載歌曲庫
- 每首歌曲配有專輯封面圖片
- 清晰顯示歌名和藝人資訊
- 當前播放歌曲以綠色高亮標示
- 點擊任一歌曲即可開始播放

### 動態播放器介面
- **智能顯示**：僅在播放音樂時出現
- **專輯封面**：大尺寸封面圖片，帶有平滑縮放動畫
- **歌曲資訊**：
  - 固定標題：「New Memories」
  - 動態藝人名稱顯示
  - 真實歌曲時長資訊
- **控制按鈕**：隨機播放切換和播放/暫停控制

### 底部迷你播放器
- 小型專輯封面預覽
- 當前播放歌曲名稱和藝人
- 可視化播放進度條
- 支援拖拽跳轉的互動滑桿

## ✨ 視覺效果與動畫

### 流暢動畫系統
- **專輯封面**：播放時的平滑縮放動畫效果
- **界面切換**：播放器視圖的滑入/滑出轉場動畫
- **列表位移**：歌曲列表根據播放器狀態智能調整位置
- **漸變效果**：文字資訊的淡入淡出過渡

### 現代設計風格
- **深色主題**：優雅的黑色背景設計
- **精心配色**：
  - 🟢 綠色：播放按鈕、進度條、當前播放標示
  - ⚪ 白色：主要文字內容
  - 🔘 灰色：次要資訊和未啟用狀態
  - 🔴 紅色：播放圖示裝飾
- **圓角設計**：專輯圖片和按鈕採用現代圓角設計
- **舒適間距**：合理的內外邊距確保最佳閱讀體驗

## 🔧 技術特色

### 錯誤處理機制
- **MediaPlayer 異常處理**：防止播放器操作失敗導致應用崩潰
- **狀態重置機制**：異常發生時自動重置到安全狀態
- **資源管理**：適當的 MediaPlayer 資源釋放和清理

### 效能優化
- **記憶體管理**：使用 `remember` 避免不必要的重組
- **協程處理**：使用 `LaunchedEffect` 處理播放進度更新
- **狀態管理**：合理的狀態分離和生命週期管理

### 本地化支援
- **Locale 設定**：時間格式化使用明確的 Locale 設定
- **地區相容性**：避免不同語言環境下的格式問題

## 📱 使用說明

### 基本操作流程
1. **瀏覽音樂庫**：在主畫面瀏覽完整歌曲列表
2. **選擇播放**：點擊想要聆聽的歌曲
3. **播放控制**：使用播放器介面控制音樂播放
4. **進度調整**：拖動底部進度條跳轉到指定位置
5. **模式切換**：開啟隨機播放享受不同的聆聽體驗

## 🎼 歌曲庫

應用程式包含 22 首預載歌曲，從 `first_song` 到 `twenty_second_song`：
- 每首歌曲都包含完整的元數據（標題、藝人、專輯圖片）
- 支援從 raw 資源自動載入音樂檔案
- 自動提取專輯封面和歌曲資訊

## 🏗️ 技術架構

### 核心技術棧
- **UI 框架**：Android Jetpack Compose
- **音樂播放**：Android MediaPlayer API
- **元數據處理**：MediaMetadataRetriever
- **圖片處理**：Bitmap 和 BitmapFactory
- **動畫系統**：Compose Animation API
- **狀態管理**：Compose State API

### 專案結構
```
src/main/java/ntou/android2025/musicplayeractivity/
├── MainActivity.kt          # 主活動和生命週期管理
└── MusicPlayerApp.kt        # 核心 UI 和邏輯實現
```
